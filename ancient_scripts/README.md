# Ancient Scripts Intelligence Platform

A language-neutral architecture for OCR, epigraphy, transliteration, low-resource translation, provenance and scholarly review across Ancient North Arabian and other ancient scripts.

## Pipeline

`image -> detection -> segmentation -> glyph recognition -> script identification -> Unicode/transliteration -> normalization -> lexical/morphological analysis -> neural translation -> retrieval/context -> confidence -> scholarly review`

The platform preserves uncertainty, damaged signs, alternate readings and provenance instead of forcing a single interpretation.

## Initial script families

Ancient North Arabian (Dadanitic, Taymanitic, Dumaitic, Safaitic, Hismaic, Thamudic B/C/D/F/Himaitic), Nabataean, Old Arabic, Aramaic, Phoenician, Paleo-Hebrew, Ugaritic, Old Persian, Egyptian, Sumerian, Akkadian and Hittite.

This registry is extensible; it does not claim that all listed scripts belong to one language family.
