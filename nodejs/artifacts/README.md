# Ancient Artifacts — Node.js + Web

A Node.js implementation of the unified artifact research layer used by the NLP/Thamudic project.

## Features

- SQLite persistent artifact database via `better-sqlite3`
- Historical object fields: period, dates, culture, material, technique, location and coordinates
- Inscription fields: script, source language, original text, transliteration, translation and confidence
- Search/filter by text, script, language, period, type and country
- Scanner endpoint for Ancient North Arabian Unicode and conservative transliteration
- Media upload with SHA-256 provenance
- Annotation and source/rights/provenance endpoints
- Browser research dashboard
- JSON API suitable for the existing Python/FastAPI application
- Evidence-first policy: recognition does not imply a scholarly translation

## Run

```bash
npm install
npm start
```

Open `http://127.0.0.1:8090/`.

## API

- `GET /health`
- `GET /api/artifacts/stats`
- `GET /api/artifacts?q=...&script_variant=...`
- `GET /api/artifacts/:id`
- `POST /api/scan` with `{ "text": "...", "script": "Ancient North Arabian" }`
- `POST /api/artifacts`
- `POST /api/artifacts/:id/annotations`
- `POST /api/artifacts/:id/provenance`
- `POST /api/artifacts/:id/media` multipart upload

The Node database is intentionally a compatible implementation, not a claim that SQLite files generated by every SQLite binding are interchangeable across all schema versions without migration. The Python database remains the canonical research implementation in this repository.
