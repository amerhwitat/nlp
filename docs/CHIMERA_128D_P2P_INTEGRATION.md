# Chimera 128D + authenticated P2P integration

The NLP/Ancient North Arabian platform participates in the common Chimera multidimensional application profile.

## 128D research state

Documents, inscriptions, glyphs, transliterations, language metadata, OCR observations and historical objects can be represented as multidimensional objects with geometry, time, observer/perspective, material/light metadata when relevant, events, properties and relationships, plus perception/cognition metadata. The 128D baseline is extensible beyond 128 dimensions.

## P2P research synchronization

Peer synchronization is opt-in and authenticated. It supports capability exchange, request/response, pub/sub, snapshot/delta synchronization and content-addressed research objects. Provenance fields must remain attached to synchronized records so a peer cannot silently replace original evidence.

The protocol never transfers credentials, private keys or arbitrary executable payloads. Network discovery is explicit/configured rather than unsolicited Internet scanning.

Python is the reference research implementation; C++, Visual C++, .NET, JavaScript/TypeScript and Node.js-compatible adapters should preserve the same logical envelope.
