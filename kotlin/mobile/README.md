# Ancient NLP Kotlin Mobile

Android Kotlin mobile implementation for the Ancient North Arabian / Thamudic research toolkit. The module is isolated from the Python, C++, VC++, and .NET implementations and is designed to consume the canonical Unicode/alphabet registry without duplicating or mutating source data.

The UI boundary is prepared for glyph classification, transliteration, RTL text, voice controls, and 128D perception-state visualization. Any network synchronization must use authenticated, opt-in P2P endpoints.
