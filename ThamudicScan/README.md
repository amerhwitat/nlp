# ThamudicScan Web Application

## Web application

Public deployment:

https://thamudicscan-s3wz30.public.builtwithrocket.new/

This deployment is the hosted web interface associated with the Thamudic / North Arabian research tooling in this repository.

## Repository relationship

The repository contains the implementation and research tooling; the public deployment provides a browser-accessible interface for the project.

## Scope

The project supports research-oriented Thamudic and related North Arabian script analysis, including the OCR/classification work maintained in this repository.
